### 주요 프로젝트

#### 🧊 [북극항로 접근성 분석](https://github.com/aquariusmin/arctic-route-accessibility-analysis)
> 기후 데이터를 물류 의사결정 단위로 환산한 재현 가능한 분석 파이프라인

- NSIDC 해빙 농도 위성 격자 데이터(1979년~, 25km)로 북극항로(NSR)의 계절별 통항 가능성을 정량화
- 대권항로에 50km 버퍼 회랑을 생성해 평균 해빙농도·병목 구간(95퍼센타일)·선급별 항행가능성 산출
- **OLS와 Theil-Sen 강건회귀를 병행해 두 방법이 일치할 때만 추세를 보고**하는 검증 규칙 적용
- **결과:** 통항 가능 기간 1980년대 연 0개월 → 2015년 이후 **연 약 3.4개월**(10년당 +0.9개월), 9월 회랑 해빙농도 **10년당 −3.2%** 감소. 수에즈 대비 약 30%(3,150해리) 거리 단축
- **재현성:** SHA-256 체크섬 데이터 매니페스트, YAML 설정 외부화, 약 30개 테스트, 멱등 파이프라인
- *확장 분석(Phase E)의 일부 리스크·기후 레이어는 실데이터 미확보 시 합성 대체값을 사용했으며 코드상 명시적으로 구분했습니다.*

#### 📉 [고객 이탈 분석 (XAI 기반)](https://github.com/aquariusmin/kw-corp-churn-strategy-analysis)
> 이탈 예측을 리텐션 실행안으로 전환

- 통신사 고객 7,043건을 정제하고 **7개 분류모델**을 7:3 분할로 비교 → Gradient Boosting 채택 (**ROC-AUC 약 0.842**)
- SHAP·의존성 분석으로 "월 단위 계약 · 짧은 가입기간 · 높은 월 요금 · 보안/기술지원 미가입"을 핵심 이탈 신호로 도출
- 세그먼트별 대응안(장기계약 전환, 온보딩 강화, 서비스 번들)을 설계하고 **이탈률 5.0%p 감소를 목표 지표로 제안**
- *5.0%p는 제안 목표이며 달성된 결과가 아닙니다. 통제된 실험을 통한 검증이 다음 단계입니다.*
- *광운대 교내 가상기업(KW-Corporation) 프로그램 과제이며, 외부 기업 인턴십이 아닙니다.*

#### 🛰️ [야간 위성 조도 기반 GDP 분석](https://github.com/aquariusmin/Satellite-GDP-Insight)
> 공식 통계가 부족한 국가의 보조 경제 지표 탐색

- VIIRS 야간 조도와 World Bank의 GDP·도시인구·전력접근성 지표를 국가-연도 단위로 통합
- 로그 변환 후 단순회귀 및 조절효과 분석 → 야간 조도가 **GDP 변동의 81.9%를 설명** (R² = 0.819)
- 도시인구·전력접근성의 상호작용 효과가 유의함을 확인
- *R²는 설명력 지표이며 예측 정확도나 인과관계를 의미하지 않습니다. 위성 관측 조건·결측·비경제적 조명이 해석을 제약합니다.*

#### ✈️ [대한항공 기업가치 분석](https://github.com/aquariusmin/koreanair_equity_research)
> 평가모형 간 충돌을 진단한 밸류에이션 케이스

- 2020~2024년 거시·산업 동향과 수익성·유동성·레버리지 지표를 연계 분석
- **DCF, APV, 유사기업 배수법**을 동시 적용, **WACC 약 2.8%** 기준 민감도 분석 및 역산 수행
- **핵심 인사이트:** 높은 CAPEX·운전자본 가정으로 FCF가 음수가 되어 절대가치평가가 불안정해지는 반면 상대가치평가는 긍정적으로 도출 → **단일 목표주가보다 가정의 품질이 평가 신뢰도를 결정**한다는 결론
- *수업 과제 기반 분석이며 투자 자문이 아닙니다. 특정 목표주가를 제시하지 않습니다.*
