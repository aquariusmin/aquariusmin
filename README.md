#### 🧊 [북극항로 접근성 분석](https://github.com/aquariusmin/arctic-route-accessibility-analysis)
> 기후 데이터를 물류 의사결정 단위로 환산한 재현 가능한 분석 파이프라인

- NSIDC 해빙 농도 위성 격자 데이터(1979년~, 25km)로 북극항로(NSR)의 계절별 통항 가능성을 정량화
- 대권항로에 50km 버퍼 회랑을 생성해 평균 해빙농도·병목 구간(95퍼센타일)·선급별 항행가능성 산출
- OLS와 Theil-Sen 강건회귀를 병행해 **두 방법이 일치할 때만 추세를 보고**하는 검증 규칙 적용
- **결과:** 통항 가능 기간 1980년대 연 0개월 → 2015년 이후 **연 3.4개월**(10년당 +0.9개월), 9월 회랑 해빙농도 **10년당 −3.2%** 감소. 수에즈 대비 **30%(3,150해리) 거리 단축**
- **재현성:** SHA-256 체크섬 데이터 매니페스트, YAML 설정 외부화, 약 30개 테스트, 멱등 파이프라인

*해석 범위 — 확장 분석(Phase E)의 일부 리스크·기후 레이어는 실데이터 미확보 구간에 합성 대체값을 사용했으며, 해당 값은 코드상 명시적으로 구분되어 있습니다.*

#### 🚇 [부산 도시철도 역세권 체류 전환 분석](https://github.com/aquariusmin/busan-station-dwell)
> 공개 데이터에 없는 '체류' 변수를 승하차 기록만으로 추정 — 2026년 Big Data 활용 대회 출품작

- 시간대별 승하차 40,544행(2026.01~06, 112개 역)에서 **누적하차 − 누적승차**로 철도 기인 순체류인구(NRP)를 구성하고, **Little's Law(L = λW)** 로 역별 평균 체류시간을 유도
- 시스템 전체 승·하차 격차가 **최대 0.748%** 임을 확인해 데이터가 개찰구 기반(내부 환승 미기록)이라는 전제를 검증한 뒤 지표 설계
- 초기 산식이 주거지형 역에서 음수로 붕괴(역-일 86.7%)하는 결함을 발견하고 **일별 최저점 기준 min-shift 보정** 적용 → 평균 체류시간 −1.23시간(불가능) → **2.78시간**으로 정상화
- 보정 과정에서 최저점·정점의 선후 관계만으로 **유입형 49개 역 / 주거형 63개 역**이 자동 분류됨
- **핵심 사례:** 해운대역 평균 체류 **0.96시간** — 유입형 49개 역 중 최하위(중앙값 2.09시간). "숙박업소 밀집 때문"이라는 대안 가설을 체크아웃 지수로 검증해 **신호는 확인(96백분위)했으나 유입의 5.8%에 그쳐 기각**

*해석 범위 — 대회 제출(2026.09)을 앞둔 진행 중 과제입니다. 상권 데이터 결합과 회귀 잔차 진단이 남아 있으며, 현재 수치는 1차 검증 단계의 결과입니다.*

#### 📉 [고객 이탈 분석 (XAI 기반)](https://github.com/aquariusmin/kw-corp-churn-strategy-analysis)
> 이탈 예측을 리텐션 실행안으로 전환

- 통신사 고객 7,043건을 정제하고 **7개 분류모델**을 7:3 분할로 비교 → Gradient Boosting 채택 (ROC-AUC 약 0.842)
- SHAP·의존성 분석으로 "월 단위 계약 · 짧은 가입기간 · 높은 월 요금 · 보안/기술지원 미가입"을 핵심 이탈 신호로 도출
- 세그먼트별 대응안(장기계약 전환, 온보딩 강화, 서비스 번들)을 설계하고 **이탈률 5.0%p 감소**를 목표 지표로 제안

*해석 범위 — 5.0%p는 제안 목표이며 달성치가 아닙니다. 통제된 실험을 통한 검증이 다음 단계입니다. 광운대학교 「광운그룹 하계인턴 가상회사 프로그램(KW-Corporation)」 수행 과제입니다.*

#### 🛰️ [야간 위성 조도 기반 GDP 분석](https://github.com/aquariusmin/Satellite-GDP-Insight)
> 공식 통계가 부족한 국가의 보조 경제 지표 탐색

- VIIRS 야간 조도와 World Bank의 GDP·도시인구·전력접근성 지표를 국가-연도 단위로 통합
- 로그 변환 후 단순회귀 및 조절효과 분석 → 야간 조도가 **GDP 변동의 81.9%를 설명** (R² = 0.819)

- 리스크 장치: 영속 킬 스위치(SQLite), 일일 손실 한도 −3%, 종목당 비중 20%, `clientOrderId` 기반 주문 멱등성, 허용 IP 변경 감시
